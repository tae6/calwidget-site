필요한 일정을 한곳에

바탕화면 위젯

월간 달력과 일정 목록을 배치하고 색상·투명도를 조절합니다. 편집 모드에서 위치와 크기를 바꿀 수 있습니다.

Google Calendar 연결

허용한 계정의 캘린더 목록과 일정을 불러옵니다. 쓰기 권한이 있는 캘린더에 일정을 추가·수정·삭제할 수 있습니다.

PC에 저장하는 일정

계정 없이 로컬 일정을 사용하거나, 연결된 캘린더를 동기화합니다. Microsoft 캘린더도 별도 앱 연결 설정으로 이용할 수 있습니다.

연결과 데이터 처리

계정 로그인과 캘린더 권한 허용은 제공업체의 브라우저 화면에서 직접 진행합니다. CalWidget은 계정 비밀번호를 받지 않습니다. 로그인 유지에 필요한 토큰과 일정 캐시는 사용자의 PC에 저장되며, 동기화할 때 해당 캘린더 제공업체와 통신합니다.

참석자가 있는 일정을 저장하면 제공업체를 통해 초대 또는 변경 알림이 전송될 수 있습니다. 자세한 저장·공유·삭제 방법은 개인정보처리방침에서 확인하세요.

Windows 10/11 x64용 개인 개발 앱입니다. Google 또는 Microsoft의 공식 제품이 아니며, 계정 연결에는 해당 서비스의 권한과 앱 연결 설정이 필요합니다.
