개인정보처리방침

최종 수정: 2026년 9월 24일 · 대상: CalWidget 1.6.0

CalWidget은 개인 개발자가 제공하는 Windows 캘린더 앱입니다. 이 방침은 데스크톱 앱과 이 안내 사이트에서 데이터를 처리하는 방법을 설명합니다.

1. 접근하는 정보와 이용 목적

  • 사용자가 연결한 계정의 캘린더 식별자, 이름, 표시 색상, 접근 권한 및 기본 알림 설정을 읽어 캘린더 목록을 표시합니다.
  • 일정 식별자, 제목, 설명, 위치, 시작·종료 시간, 시간대, 종일 여부, 반복 정보, 참석자 이메일, 알림, 색상 및 공개·바쁨 설정 등을 처리하여 일정을 표시하고 동기화합니다. 처리 항목은 제공업체와 일정에 따라 달라집니다.
  • 사용자가 요청한 일정 추가·수정·삭제를 연결된 계정에 반영합니다. 읽기 전용 캘린더에는 변경 사항을 저장할 수 없습니다.
  • 계정 연결 정보와 OAuth 액세스·갱신 토큰은 인증 및 로그인 유지에 사용합니다. 계정 비밀번호는 CalWidget이 입력받거나 저장하지 않습니다.
  • 화면 설정과 로컬 일정은 위젯 표시 및 계정 없이 사용하는 캘린더 기능에 사용합니다.

2. Google 권한

CalWidget은 캘린더 목록 조회를 위한 calendar.calendarlist.readonly와 일정 조회·추가·수정·삭제를 위한 calendar.events 권한을 요청합니다. 사용자가 Google 동의 화면에서 허용한 범위에서만 접근합니다. Microsoft 계정 연결 시에는 일정 읽기·쓰기와 로그인 유지를 위한 권한을 요청합니다.

3. 저장 위치와 보호 방법

앱 데이터는 기본적으로 사용자 PC의 %LOCALAPPDATA%\CalWidget에 저장됩니다. 계정 토큰과 OAuth 앱 연결 프로필은 Windows의 사용자별 데이터 보호 기능(DPAPI)으로 암호화합니다. 일정 내용과 화면 설정은 별도로 암호화되지 않은 JSON 파일에 저장됩니다. PC와 Windows 계정의 접근 권한을 보호해 주세요.

복구를 위한 백업 파일 및 손상 파일 사본이 남을 수 있습니다. 연결 진단 로그는 시각, 제공업체, 처리 단계와 오류 코드를 로컬에 기록합니다. 진단용 실행 시 데이터 경로·항목 수 등의 로컬 상태 파일도 생성될 수 있습니다.

4. 전송·공유 및 제한적 사용

앱은 인증과 동기화를 위해 Google 또는 Microsoft의 서버와 HTTPS로 직접 통신합니다. CalWidget 개발자가 운영하는 별도 서버로 일정이나 로그인 토큰을 수집하는 기능은 없습니다. 참석자를 지정한 일정을 저장할 때에는 일정 내용과 참석자 정보가 해당 제공업체로 전송되고, 제공업체를 통해 초대·변경 알림이 참석자에게 전달될 수 있습니다.

CalWidget은 Google 사용자 데이터를 판매하거나 광고 타기팅, 신용평가 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. Microsoft 서비스에는 해당 제공업체의 정책도 적용됩니다.

5. 보관 기간과 삭제·권한 철회

앱 데이터는 사용자가 삭제할 때까지 PC에 남을 수 있습니다. 앱 제거만으로 사용자 데이터가 모두 삭제되지는 않습니다.

  1. 앱의 설정 → 연결 계정에서 계정을 연결 해제하면 해당 계정 정보와 현재 일정 캐시가 제거됩니다. 과거 일정이 포함된 로컬 백업 사본은 남을 수 있습니다.
  2. Google의 접근 권한까지 철회하려면 Google 계정의 서드 파티 연결 관리에서 CalWidget에 사용한 앱의 연결을 삭제하세요. 앱 안에서 연결 해제하는 것만으로 Google 측 동의가 철회되지는 않습니다. Microsoft 계정은 해당 계정의 앱 권한 관리에서 철회할 수 있습니다.
  3. 로컬 백업·설정·연결 프로필을 포함한 모든 앱 데이터를 삭제하려면 CalWidget을 완전히 종료한 뒤 위 데이터 폴더를 삭제하세요. 로컬 전용 일정도 함께 삭제되므로 먼저 필요한 내용을 보존하세요. 별도로 내보내거나 복사한 파일은 해당 위치에서도 삭제해야 합니다.

연결 해제나 PC의 데이터 삭제는 Google/Microsoft 서버에 저장된 원본 일정을 삭제하지 않습니다. 원본 일정은 해당 캘린더에서 직접 삭제할 수 있습니다.

6. 안내 사이트와 문의

이 사이트는 GitHub Pages에 게시하는 정적 안내 사이트이며 방문자 로그인, 자체 분석 도구 또는 광고 추적 코드를 사용하지 않습니다. 호스팅 제공자인 GitHub는 사이트 제공과 보안을 위해 IP 주소 등의 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인하세요.

문의 이메일을 보내면 회신을 위해 이메일 주소와 문의 내용을 처리합니다. 비밀번호, 인증 코드, 토큰 또는 비밀 키를 보내지 마세요. 문의 내용의 삭제를 요청할 수 있습니다.

7. 방침 변경

데이터 처리 방식이 바뀌면 이 페이지의 방침과 수정 날짜를 갱신합니다. 새로운 목적이나 권한으로 데이터를 이용할 경우 필요한 안내와 동의 절차를 진행합니다.
